# Q-001 — Which experiment has highest expected information gain?

**Status:** OPEN

Can Faraday rank candidate experiments by how strongly their possible outcomes distinguish competing hypotheses rather than by novelty or implementation convenience?

Candidate framing:

```text
expected information gain ≈
uncertainty over hypotheses before experiment
− expected uncertainty after observing experiment outcome
```

This requires explicit competing hypotheses and calibrated beliefs; it should not be presented as objective truth when those inputs are subjective.
